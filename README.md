# research_pipeline_overleaf_drawio

从一次 ICLR 论文协作中整理的可复用流程：广泛调研 → idea 与 baseline → 基座、模型与算法实现 → 实验 → Draw.io → Overleaf → 持续维护。

重点记录研究者怎样纠正 Codex 的画图、写作与执行偏差。**75 条聊天原话与经验**，每条一两句话；配套 **12 份论文图当前稿、26 份论文 PDF，以及 18 份完整多页 Draw.io 工作文件**。

## 阅读入口

| 文件 | 内容 |
|---|---|
| [PIPELINE.md](PIPELINE.md) | 调研、实现、实验的 12 条要求与阶段输出 |

| [WRITING.md](WRITING.md) | 写作与 Overleaf 的 30 条纠正：逐句、公式、结构、版面 |

## 图稿与完整包

- [drawio/](drawio/)：当前采用页面组成的 12 份可编辑文件，便于打开与复用。
- [figures/](figures/)：2026-09-26 论文快照实际引用的 26 份 PDF。
- [v1.0 完整工作文件](https://github.com/Yutenji-Nyamu/research_pipeline_overleaf_drawio/releases/tag/v1.0-20260927)：12 份论文源文件与 6 份素材库、案例合集，保留全部页面、批注、备选和历史版本。
- [manifest.json](manifest.json)：每个源文件、页面与导出文件的名称、大小和 SHA-256 校验值。

当前页来自 2026-09-27 归档时的工作文件；论文图号依据 2026-09-26 稿件。源图页名与 PDF 文件日期分别列在索引中，方便追踪两者对应的版本。

## 如何复用

先读本轮工作的专题清单，再打开同类图稿和 PDF，明确参考哪个整体构图或局部组件。将原始数据、统计口径和研究者的具体要求写进任务交接，按批注迭代，交付时填写修改记录。

原话检索自 2026 年 7–9 月本机现存研究聊天；引号内保留原文，随后一句是经验归纳。每条附日期和聊天名。研究者负责问题、设计、叙事与最终选择，Codex 负责落实并记录。

整理日期：2026-09-27。素材出处与复用说明见 [REFERENCES.md](REFERENCES.md)。
